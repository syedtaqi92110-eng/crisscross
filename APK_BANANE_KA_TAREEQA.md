# APK banane ka tareeqa (5 minute, free)
1. github.com par free account banayen -> New repository (naam: crisscross).
2. Is folder ki saari files upload karein (Add file -> Upload files). `.github` folder bhi zaroor.
3. Repo mein Actions tab kholen -> "Build Android APK" -> Run workflow.
4. 4-5 minute baad run complete hoga. Us par click karke neeche Artifacts se `CrissCross-APK` download karein.
5. Zip kholen, `app-debug.apk` apne phone mein bhejein aur install karein
   (Settings mein "Install unknown apps" allow karna hoga).
